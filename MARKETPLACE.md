**Tagline:** Provision HTTPS agent services from PeltyCMS orders

## HTTPS agent provisioning for PeltyCMS

Create, suspend, unsuspend and terminate customer services on HTTPS agent when orders are paid or cancelled. Credentials stay in Pelty secrets; the module runs as sandboxed WASM.

### Features
- Create / suspend / unsuspend / terminate
- Password + package sync hooks
- Works with Pelty product module mapping
- MythicCloud panel download supported

### Requirements
- Reachable HTTPS agent API/panel
- API token or login configured in Pelty
